# StrikeZone Mobile

Original Godot 4 mobile arena prototype.

Features: menu, 5 rounds, arena map, four bots, touch HUD, swipe camera, jump, and a non-realistic tag mechanic.

The visuals are procedural so the first APK builds without downloading external assets. Free licensed environment/character assets can be added later.

Open strikezone/project.godot in Godot 4.x and run Main.tscn.
